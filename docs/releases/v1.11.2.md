# challenge-kit v1.11.2

This patch requires Go 1.27.4 and selects `secure-kit/v2` v2.1.5. Go 1.27.4
carries security fixes to cgo, the go command, the compiler, the linker and
`net/http`. secure-kit v2.1.5 updates `golang.org/x/crypto` to v0.59.0.

Public APIs, Argon2 challenge hashes, Redis key formats, namespaces, TTLs and
lockout behavior are unchanged from v1.11.1. No challenge-kit source file other
than `go.mod` and `go.sum` changed.

## Upgrade and rollback

```sh
go get github.com/soulteary/challenge-kit@v1.11.2
```

Rebuild callers with Go 1.27.4 or newer. No namespace or data migration is
required when upgrading from v1.11.1. Rolling back to v1.11.1 needs no data
change; it restores the Go 1.27.3 requirement and the previous dependency
versions.

For the verification and activation guidance that applies to both versions, see
the [v1.11.1 notes](v1.11.1.md).
